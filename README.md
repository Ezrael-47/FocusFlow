## ⚙️ How to Use

1. **Clone or download** the repository.
2. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari).
3. No build tools or server required — it runs fully client‑side.

### Timer
- Set focus and break durations (in minutes).
- Click **Start** to begin the countdown.
- Use **Pause** and **Reset** as needed.
- When a focus session ends, a notification will appear (if permitted).

### Tasks
- Type a task and press **Add** or hit **Enter**.
- Click the **check** icon to mark as done/un‑done.
- Click the **trash** icon to delete.
- **Drag** the handle (≡) to reorder tasks.

### Notes
- Write anything in the notes area; it auto‑saves after a short pause.

### Ambient Sounds
- Click any sound button to play. Click **Off** to stop.
- Sounds are generated locally (no external audio files).

### Statistics
- The chart updates automatically based on your tasks and completed Pomodoros.
- Daily stats reset each day (based on your local date).

---

## 🧪 Browser Support

- **Modern browsers** (Chrome 60+, Firefox 55+, Edge 79+, Safari 14+)
- Requires `localStorage` and `Web Audio API` support.
- Dark mode uses CSS custom properties.

---

## 📦 Dependencies (CDN)

- [Font Awesome 6](https://fontawesome.com/) — icons
- [Chart.js 3](https://www.chartjs.org/) — chart rendering

Both are loaded via CDN in the `<head>` of `index.html`. No installation needed.

---

## 🛡️ Privacy & Data

All data is stored **exclusively in your browser's localStorage**. No data is sent to any server. The ambient sounds are generated locally using the Web Audio API — no external files or tracking.
